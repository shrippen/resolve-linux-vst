resolve
-linux-vst

VST2 and VST3 plug-ins for DaVinci Resolve on Linux, plus AAC audio and Nikon N-RAW. One small preload library fills in what the Linux build leaves out. Resolve's own files stay untouched.

VST2- und VST3-Plugins für DaVinci Resolve unter Linux, dazu AAC-Ton und Nikon N-RAW. Eine kleine Preload-Bibliothek ergänzt, was der Linux-Version fehlt. Resolves eigene Dateien bleiben unangetastet.

curl -fsSL https://raw.githubusercontent.com/shrippen/resolve-linux-vst/main/install.sh | bash

Installs into ~/.local, no root. Adds a menu entry “DaVinci Resolve (VST)” and checks your Resolve version.

Installiert nach ~/.local, ohne root. Legt den Menüeintrag „DaVinci Resolve (VST)“ an und prüft deine Resolve-Version.

VST2

The missing loader

Der fehlende Lader

Resolve on Linux has the whole VST host, but the function that loads a plug-in is empty. resolve-linux-vst supplies it: native Linux plug-ins and Windows plug-ins through yabridge appear in the Fairlight effects library.

Resolve unter Linux hat den ganzen VST-Host, nur die Funktion, die ein Plugin lädt, ist leer. resolve-linux-vst liefert sie nach: Native Linux-Plugins und Windows-Plugins über yabridge erscheinen in der Fairlight-Effektbibliothek.

VST3

VST3 through an adapter

VST3 über einen Adapter

Each VST3 plug-in shows up as a VST2 plug-in: audio, parameters and automation, state, editor. Tested with iZotope, Waves, ToneBoosters and MiniMeters.

Jedes VST3-Plugin erscheint als VST2-Plugin: Audio, Parameter und Automation, Zustand, Editor. Getestet mit iZotope, Waves, ToneBoosters und MiniMeters.

HiDPI

Editors in the right size

Editoren in der richtigen Größe

On scaled screens editors get Resolve's factor, JUCE and VST3 plug-ins are told to draw at it, and Wine plug-ins get a DPI per plug-in that is set back when Resolve exits.

Auf skalierten Bildschirmen bekommen Editoren Resolves Faktor, JUCE- und VST3-Plugins zeichnen damit, und Wine-Plugins bekommen eine DPI je Plugin, die nach dem Beenden zurückgesetzt wird.

LibraryBibliothek

Sorted, not “Uncategorized”

Sortiert statt „Unsortiert“

Plug-ins land in Resolve's own categories (Dynamics, EQ, Reverb, …), computed the way Resolve does on Windows. What you sort yourself stays.

Plugins landen in Resolves eigenen Kategorien (Dynamik, EQ, Hall, …), berechnet wie Resolve es unter Windows tut. Was du selbst einsortierst, bleibt.

AAC

Clips with sound

Clips mit Ton

MP4, MOV and M4A with AAC audio from phones, cameras and screen recorders play with sound, through a small AAC-only build of FFmpeg 6.0. No converting first.

MP4, MOV und M4A mit AAC-Ton von Handys, Kameras und Bildschirmaufnahmen spielen mit Ton, über einen kleinen FFmpeg-6.0-Build nur mit AAC. Ohne vorher umzuwandeln.

AAC

Renders that play in the browser

Renders, die im Browser spielen

With an AAC encoder plug-in Resolve writes MP4s without the AAC profile, and browsers play them silently. resolve-linux-vst adds the missing description before the file is written.

Mit einem AAC-Encoder-Plugin schreibt Resolve MP4s ohne AAC-Profil, Browser spielen sie stumm. resolve-linux-vst ergänzt die fehlende Angabe, bevor die Datei geschrieben wird.

N-RAW

Nikon N-RAW

Nikon N-RAW

Resolve's RED decoder reads N-RAW once the file is called .R3D. resolve-linux-vst shows every .nev that way, read-only, without renaming anything on disk.

Resolves RED-Decoder liest N-RAW, sobald die Datei .R3D heißt. resolve-linux-vst zeigt jede .nev so, nur lesend, ohne auf der Platte etwas umzubenennen.

UpdatesUpdates

Checks itself

Prüft sich selbst

Hooks without symbols are found by byte patterns, not fixed addresses. After a Resolve update, resolve-linux-vst check shows what still matches, before you start it.

Einhängepunkte ohne Symbole findet es über Byte-Muster statt fester Adressen. Nach einem Resolve-Update zeigt resolve-linux-vst check, was noch passt, bevor du startest.

Waves

Big plug-in shells

Große Plugin-Shells

Waves shells with hundreds of plug-ins work, an ignore list keeps out what you do not need, and a yabridge plug-in group opens further Waves plug-ins in 30 ms.

Waves-Shells mit Hunderten Plugins funktionieren, eine Ignorierliste hält fern, was du nicht brauchst, und eine yabridge-Plugingruppe öffnet weitere Waves-Plugins in 30 ms.

How it works

So funktioniert es

The launcher resolve-linux-vst starts Resolve with libresolve-linux-vst.so preloaded. Where Resolve calls a function by name, the library's function of the same name wins. Where Resolve's code lacks a hook, the library adjusts it in memory at startup, after checking that the code is what it expects.

Der Starter resolve-linux-vst startet Resolve mit vorgeladener libresolve-linux-vst.so. Wo Resolve eine Funktion beim Namen ruft, gewinnt die gleichnamige Funktion der Bibliothek. Wo Resolves Code keinen Einhängepunkt hat, passt die Bibliothek ihn beim Start im Speicher an, nachdem sie geprüft hat, dass der Code ist, was sie erwartet.

Install and set up

Installieren und einrichten

  1. Run the installer: curl -fsSL https://raw.githubusercontent.com/shrippen/resolve-linux-vst/main/install.sh | bash. It needs Linux on x86_64, Resolve in /opt/resolve, and nm (binutils).
  2. Start Resolve with DaVinci Resolve (VST) from your menu, or run resolve-linux-vst.
  3. In Resolve, Preferences → User → Audio Plugins → VST Plugin Paths: add ~/.local/share/resolve-linux-vst/vst and let it scan.
  4. Your plug-ins are in the Effects Library → Audio FX. AAC and N-RAW clips need no setup.
  1. Installer ausführen: curl -fsSL https://raw.githubusercontent.com/shrippen/resolve-linux-vst/main/install.sh | bash. Braucht Linux auf x86_64, Resolve in /opt/resolve und nm (binutils).
  2. Resolve über DaVinci Resolve (VST) im Menü starten oder resolve-linux-vst ausführen.
  3. In Resolve unter Einstellungen → Benutzer → Audio-Plugins → VST-Plugin-Pfade den Ordner ~/.local/share/resolve-linux-vst/vst hinzufügen und scannen lassen.
  4. Die Plugins stehen in der Effektbibliothek → Audio-FX. AAC- und N-RAW-Clips brauchen keine Einrichtung.

Questions

Fragen

Does it change my Resolve installation?Ändert es meine Resolve-Installation?

No. Everything happens in memory while Resolve runs. Start Resolve without resolve-linux-vst and it is the stock program again. Resolve's own plug-in list and preferences are the only files it writes to, and it keeps a backup of the list.

Nein. Alles passiert im Speicher, solange Resolve läuft. Startest du Resolve ohne resolve-linux-vst, ist es wieder das unveränderte Programm. Geschrieben werden nur Resolves Plugin-Liste und Einstellungen, von der Liste mit Sicherung.

What happens after a Resolve update?Was passiert nach einem Resolve-Update?

Run resolve-linux-vst check. A hook that no longer matches switches off only its own feature; Resolve itself keeps working and the log says what was skipped. Code sites are found by byte patterns, so most updates need no change.

resolve-linux-vst check ausführen. Ein Einhängepunkt, der nicht mehr passt, schaltet nur seine eigene Funktion ab; Resolve selbst läuft weiter, und das Log sagt, was ausgelassen wurde. Code-Stellen werden über Byte-Muster gefunden, die meisten Updates brauchen deshalb keine Änderung.

Does it work with the free version of Resolve?Geht es mit der kostenlosen Version von Resolve?

It is tested with Resolve Studio 21.1.1 only. The free version shares most of the code, but it is untested; resolve-linux-vst check shows which hooks it finds there.

Getestet ist es nur mit Resolve Studio 21.1.1. Die kostenlose Version teilt den meisten Code, ist aber ungetestet; resolve-linux-vst check zeigt, welche Einhängepunkte es dort findet.

Instruments, sidechain, LV2, CLAP?Instrumente, Sidechain, LV2, CLAP?

Effects only: no MIDI input, no sidechain inputs, no ARA. LV2 and CLAP plug-ins work through Carla, which is a VST2 plug-in itself and hosts them inside.

Nur Effekte: kein MIDI-Eingang, keine Sidechain-Eingänge, kein ARA. LV2- und CLAP-Plugins gehen über Carla, das selbst ein VST2-Plugin ist und sie darin lädt.

Can I render AAC with it?Kann ich damit AAC rendern?

Encoding needs an encoder plug-in such as FDK-AAC. resolve-linux-vst makes its MP4 and MOV files complete, so browsers play the sound.

Zum Kodieren braucht es ein Encoder-Plugin wie FDK-AAC. resolve-linux-vst macht dessen MP4- und MOV-Dateien vollständig, damit Browser den Ton abspielen.
